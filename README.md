# SupportDesk

SupportDesk is an internship project for exploring a support-desk application. The repository currently contains existing source code under `src/` and project notes under `docs/`, alongside the monorepo directory placeholders below.

## Repository structure

- `apps/api/` — reserved for the API application.
- `apps/web/` — reserved for the web application.
- `apps/mobile/` — reserved for the mobile application.
- `agents/` — reserved for agent-related project resources.
- `automation/n8n/` — reserved for n8n automation resources.
- `postman/` — reserved for API request collections and related files.
- `infra/` — reserved for infrastructure configuration.
- `docs/` — project documentation, including the existing prompt journal.
- `.github/workflows/` — reserved for GitHub Actions workflows.
- `src/` — existing project source; preserved as-is.

## Current setup status

The monorepo folders are organizational placeholders; no new API, web, mobile, or infrastructure implementations are included. Existing source files, package manifests, and documentation are preserved. No dependencies were installed as part of this setup. The current `package.json` still contains its existing placeholder test script.
